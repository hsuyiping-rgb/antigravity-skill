# 一次安裝全部技能（Antigravity 版）

依序載入並執行：

1. ag-env-setup — 環境建置
2. ag-notebooklm — NotebookLM
3. ag-github — GitHub
4. ag-obsidian — Obsidian
5. ag-second-brain — 第二大腦
6. ag-supabase — Supabase
7. ag-firebase — Firebase
8. ag-ollama — 本地 AI
9. ag-gemini — Gemini API
10. ag-workspace — 老師建專案
11. ag-draw — 生圖技能

每完成一個報告進度，最終回報總表：11 項各別的成功/失敗/已跳過狀態。
